# CoverTint

**Цвета любимой музыки — во всём приложении.**

Аддон для Яндекс Музыки с модом **PulseSync**. Подстраивает фон, нижний плеер, текст и иконки под палитру текущего трека, сохраняя привычное расположение элементов.

**Версия:** 1.0 · **Автор:** [ogressar](https://github.com/ogressar)

### [Скачать CoverTint 1.0 (.pext)](downloads/CoverTint-1.0.pext?raw=true)

## Возможности

- Адаптивные цвета меняются вместе с треком, даже при закрытом большом плеере.
- Мягкое затемнение ярких оттенков и коррекция контраста текста.
- Нижняя панель плеера в одной цветовой гамме с приложением.
- Квадратный значок **E** вместо исходной отметки explicit — по желанию.
- Пять переключателей во вкладке **Настройки** PulseSync.

## Установка

1. Установите PulseSync и его мод для Яндекс Музыки.
2. Скачайте `.pext` по ссылке выше и импортируйте его в PulseSync.
3. Включите CoverTint и полностью перезапустите Яндекс Музыку.
4. Откройте карточку CoverTint → **Настройки**, чтобы выбрать оформление.

При переходе с тестовой версии 1.6.3 выберите замену существующего аддона. Оставьте включённой только одну версию CoverTint. Другие аддоны, одновременно меняющие палитру, могут конфликтовать с ним.

## Настройки

| Настройка | Что делает | По умолчанию |
| --- | --- | --- |
| Адаптивные цвета | Оформление по палитре текущего трека | Включено |
| Значок E | Заменяет отметку explicit; работает независимо от палитры | Включено |
| Оттенок текста и иконок | Цветные акценты; при выключении — нейтральные светлые тона | Включено |
| Более тёмный фон | Дополнительно затемняет фон, сохраняя оттенок | Выключено |
| Плавная смена цветов | Переходы основных панелей с учётом уменьшения анимации в системе | Включено |

## Как работает

Используется готовая палитра `derivedColors` текущего трека через API PulseSync. Если она недоступна, аддон пробует прочитать фон открытого большого плеера. Пока нет ни одного источника, сохраняется предыдущая палитра, а при первом запуске — исходное оформление.

Совместимость: формат аддонов `script`, API `window.pulsesyncApi.getCurrentTrack()` и `getSettings()`. Реализация зависит от классов интерфейса Яндекс Музыки, поэтому после обновлений приложения отдельные элементы могут потребовать доработки. Это не точная копия формулы штатного полноэкранного фона.

## Исходники и сборка

Репозиторий создан из [PulseSync-ExampleAddon](https://github.com/PulseSync-LLC/PulseSync-ExampleAddon). Его структура адаптирована под существующий CoverTint 1.0 в формате `script`: React/WebHost из нового шаблона не используется.

- `src/main.js` — логика и динамические стили.
- `src/styles.css` — статический CSS.
- `addon.config.mjs` — метаданные.
- `addon/handleEvents.json` — схема настроек.
- `addon/README.md` — описание внутри PulseSync.
- `downloads/` — установочный пакет 1.0.

Для сборки нужен Node.js 20 или новее; сторонние пакеты устанавливать не требуется:

```sh
npm run check
npm test
npm run build
```

Готовая папка аддона: `dist/CoverTint/`. Для импорта упакуйте **содержимое** этой папки ZIP-архиватором и задайте расширение `.pext` (файл `metadata.json` должен лежать в корне архива).

Пользовательский `pulsesync.settings.json` не включайте в публикацию.
